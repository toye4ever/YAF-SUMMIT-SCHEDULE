# YAF USA Revival Summit 2026 Program

Static event schedule website for the YAF USA Revival Summit 2026 — REVIVE 2.0.

## Deploy on Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Leave the framework preset as **Other**.
5. Leave the build command and output directory empty.
6. Select **Deploy**.

The site entry point is `index.html`; no build step or environment variables are required.
